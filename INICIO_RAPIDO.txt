CÓMO EMPEZAR
═════════════════════════════════════════════════════════════════════════════

1. LEER DOCUMENTACIÓN
   → Abre: DOCUMENTACION_COMPLETA_CONSOLIDADA.md
   → Sección: "10. SISTEMA DE PERMISOS BASADO EN ROLES"

2. PROBAR EL SISTEMA
   → npm run dev
   → Ir a: http://localhost:5173/auth/login
   → Usuario: admin
   → Contraseña: 123
   → Rol: Seleccionar ADMINISTRADOR (botones verdes)

3. IMPLEMENTAR EN COMPONENTES
   → Usa el hook usePermissions()
   → Ejemplo:
     
     import { usePermissions } from '@/hooks/usePermissions';
     
     function MiComponente() {
       const { can } = usePermissions();
       
       if (can("usuarios", "edit")) {
         return <EditButton />;
       }
     }

CUANDO LLEGUE EL BACKEND
═════════════════════════════════════════════════════════════════════════════

Solo necesitas cambiar UNA LÍNEA en:
  → src/features/auth/services/authService.js

De:
  const user = await mockLogin(username, password);

A:
  const response = await axios.post("/api/auth/login", { username, password });
  const user = response.data;

Backend debe retornar:
  {
    id: number,
    username: string,
    name: string,
    email: string,
    avatar: string | null,
    role: "ADMINISTRADOR" | "COORDINADOR" | ...
  }

EJEMPLOS RÁPIDOS DE USO
═════════════════════════════════════════════════════════════════════════════

VERIFICAR PERMISO:
  const { can } = usePermissions();
  if (can("usuarios", "delete")) {
    // Usuario puede eliminar usuarios
  }

MENÚ DINÁMICO:
  const { getModules } = usePermissions();
  const modules = getModules(); // ["dashboard", "usuarios", ...]

VALIDAR MULTI-ROL:
  const { hasAnyRole } = usePermissions();
  if (hasAnyRole(["ADMINISTRADOR", "COORDINADOR"])) {
    // Usuario es admin o coordinador
  }
