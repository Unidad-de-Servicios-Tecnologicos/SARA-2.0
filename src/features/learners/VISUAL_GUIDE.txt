│                         PUNTOS CLAVE DEL DISEÑO                             │
└────────────────────────────────────────────────────────────────────────────┘

🎯 ENCABEZADO STICKY
   └─ Se queda arriba al hacer scroll
   └─ Muestra siempre: nombre, estado, ficha, programa
   └─ Botón X para cerrar en la esquina

📄 CONTENIDO SCROLLABLE
   └─ 5 secciones bien delimitadas
   └─ Información clara y organizada
   └─ Sin tabs, todo visible en un scroll

🔧 ACCIONES STICKY BOTTOM
   └─ Se queda abajo al hacer scroll
   └─ 4 botones de acciones frecuentes
   └─ Callbacks listos para integrar

🎨 DISEÑO RESPONSIVE
   └─ Desktop: 384px (w-96 Tailwind)
   └─ Tablet: 384px
   └─ Móvil: 100% del ancho

🌓 TEMA OSCURO/CLARO
   └─ Colores con dark: prefix
   └─ Bordas oscuras en dark mode
   └─ Texto legible en ambos temas

│                         INTERACCIÓN                                         │
└────────────────────────────────────────────────────────────────────────────┘

ABRIR PANEL:
  1. Usuario hace clic en fila de tabla
  2. Se llama handleViewLearner(learner)
  3. setSelectedLearner(learner)
  4. setShowDetailPanel(true)
  5. Panel se desliza desde la derecha

CERRAR PANEL:
  1. Usuario hace clic en X arriba
     ↓ Se ejecuta onClose()
  2. Usuario hace clic en overlay gris
     ↓ Se ejecuta onClose()
  3. Panel se desliza hacia la derecha
  4. showDetailPanel = false

NAVEGAR EN ACCIONES:
  1. Usuario hace clic en "Ver RAPS"
  2. Se ejecuta onViewRaps()
  3. Navega a /learners/{id}/raps
  4. Panel puede cerrarse automáticamente
